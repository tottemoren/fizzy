# 0. アプリの全体像

## Fizzy とは
チームの「やること」や「アイデア」をカードで管理する、かんばん型のタスク管理ツール。
37signals（Basecamp・HEY の開発元、Ruby on Rails の生みの親）が [fizzy.do](https://fizzy.do/) で有料 SaaS として提供しており、
そのソースコードが公開されている。

## データの構造

```
アカウント（会社・チーム）
 └ ボード（プロジェクト単位）
     └ 列（カラム）（例：「対応中」「レビュー待ち」）
         └ カード（1つのタスク・アイデア）
             ├ 説明文・画像
             ├ コメント・リアクション・@メンション
             ├ 担当者・タグ・色
             └ ステップ（チェックリスト）
```

## カードのライフサイクル（Fizzy の特徴）

```
新規カード
   ↓
MAYBE?（トリアージ待ち）… どの列にも入っていない受付箱
   ↓ 振り分け
列に入る（対応中など）
   ↓
├→ DONE（完了）
├→ NOT NOW（今はやらない）
└→ 一定期間動きがない → 自動で NOT NOW へ（エントロピー）
```

| 状態・機能 | 意味 | コード |
|-----------|------|--------|
| トリアージ | 新規カードを列に振り分ける | [card/triageable.rb](../../app/models/card/triageable.rb) |
| Not Now | やらないが捨てもしない保留 | [card/postponable.rb](../../app/models/card/postponable.rb) |
| エントロピー | 放置カードを自動で Not Now へ移す | [card/entropic.rb](../../app/models/card/entropic.rb) |
| 完了 | カードを閉じる | [card/closeable.rb](../../app/models/card/closeable.rb) |
| ゴールデン | 重要カードを一覧の先頭に表示 | [card/golden.rb](../../app/models/card/golden.rb) |

その他：通知（メール・プッシュ）、ウォッチ、全文検索、ボードの一般公開、Webhook、エクスポート／インポート、
マジックリンク・パスキーによるログイン。

## 実際に触って気づいたこと
- カード詳細に「30日間動きがなければ Not Now へ移動」と表示され、エントロピーがUIにも表れている
- URL が `/{アカウントID}/cards/{番号}` の形になっており、マルチテナントが URL ベースで実装されている
- ショートカットキー（`C` 作成、`D` 完了、`K` 検索など）が画面上に表示されている
