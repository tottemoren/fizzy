# 学習ノート — Fizzy コードリーディング

37signals の商用かんばんツール Fizzy を題材に、実務コードを観点ごとに読み解いたノートです。
各ノートには **該当コードへのリンク** と **自分の考え** を記録しています。

> `docs/` 直下の `development.md` などはフォーク元の公式ドキュメントです。
> 自分の学習ノートはすべてこの `docs/study/` にまとめています。

## 読み進め方
1. `config/routes.rb` から機能の全体像を把握する
2. 1機能（例：カードを閉じる）を「ルート → コントローラー → モデル → ビュー → テスト」と縦に追う
3. `git log` / `git blame` で設計の変遷を確認する
4. 学んだことを自分の言葉でノートにまとめる
